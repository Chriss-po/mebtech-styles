# MebTech v5.4.0 RC2 — PDP UX/UI Refinements

**Tag:** `v5.4.0-rc.2`  
**Target:** `main`  
**Release type:** Pre-release — Pending Production QA

## Overview
Second release candidate for the MebTech product detail page (PDP). It consolidates approved visual refinements and preserves PrestaShop/IQIT product, cart, and payment mechanics.

## Changes since v5.4.0 RC1

### Short description placement
- Moves the original native `product-description-short-*` element below the `У кошик` purchase section across all PDPs.
- Preserves the source content, links, and AJAX refresh handling.
- Catalog-only items without a purchase action retain readable descriptions.

### Price clarification — Warning Alert
- Changes `Актуальну ціну уточнюйте у менеджера.` from neutral Info to the approved amber Warning style after customer feedback about missed price qualifications.
- Keeps the notice adjacent to the price, with a 6px gap.
- Uses approved Warning tokens and dimensions: Amber BG `#FAF0DC`, Amber text `#9C6B0B`, 0.5px Amber border at 20% opacity, Inter 13px, 12px × 16px internal padding.
- Original wording and pricing logic remain unchanged.

## Retained from RC1
- DS Info alert for the preorder delivery message.
- DS Warning alert for Nova Poshta board-shipping restrictions.
- Amber visual preorder status for the half-sheet format.
- Shipping display: hardware retains stated Nova Poshta prices; other categories display `За тарифами перевізника`.
- Service pickup and delivery readiness phrasing.
- Restored PDP v5.3 Core + REPLACEMENT 05 in the generated JavaScript bundle.
- Existing approved region switch and furniture-project CTA.

## Build
- `dist/mebtech.css`: verified generated CSS includes Warning price styling, relocated-description styling, and carrier tariff wrapping.
- `dist/mebtech.js`: verified generated JS includes under-cart description placement, price-info anchoring, half-sheet preorder visual status and delivery-copy handling.
