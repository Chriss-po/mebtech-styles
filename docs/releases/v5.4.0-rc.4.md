# MebTech v5.4.0 RC4 — Mobile PDP Layout Fix

**Tag:** `v5.4.0-rc.4`  
**Target branch:** `main`  
**Release type:** Pre-release · Pending Production QA

## Overview
Targeted mobile layout correction for the MebTech product detail page based on the live furniture-project PDP screenshot and inspected PrestaShop/IQIT DOM.

## Changes since v5.4.0 RC3

### Shared mobile gutters
- Applied a consistent **16px horizontal gutter** to `#inner-wrapper.container` on PDPs at viewport widths up to 767px.
- Covers product title, gallery, project description, specifications and related-product sections within the same content container.
- Neutralized conflicting negative Bootstrap row margins and redundant child-level side padding.
- Kept the global header and desktop layout unchanged.
- Avoided double-padding individual cards or related-product blocks.

## Carried forward from RC3
- Short description below Add to Cart only when the product has a usable native purchase button and positive price.
- For non-purchasable/status-only PDPs, short description stays visible outside the hidden purchase form.
- Reduced short-description spacing (8px top / 16px bottom) and corrected no-price header spacing.
- Existing approved PDP Alert, availability, delivery and price-info refinements.

## Verified in GitHub
- `dist/mebtech.css` includes the shared mobile gutter and earlier layout fixes.
- `dist/mebtech.js` includes the non-purchasable product short-description handling.

## QA checklist
- Mobile furniture project without price / Add to Cart.
- Normal purchasable PDP (including variant changes).
- 360px and 390px viewports, and desktop breakpoint transition.
- Description, features and related-product carousels: 16px side gutters without horizontal page overflow.
- Confirm no duplicate CSS/JS imports.

**Pre-release — Pending Production QA.** The above builds are present on `main`; production appearance has not yet been confirmed. Keep `v5.4.0-rc.3` for rollback.
